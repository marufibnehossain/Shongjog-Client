# Shongjog

Shongjog is a community-driven social development event platform that helps people discover, create, and participate in meaningful community service events.

## Live Site

https://shongjog-one.vercel.app

## Features

- Create and manage community service events
- Discover upcoming community events
- Join events and manage joined events
- Google and GitHub authentication
- JWT-protected APIs
- User profile and profile image management
- Light and dark theme support
- Responsive design for mobile, tablet, and desktop

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- Better Auth
- Express.js
- MongoDB
- JWT
